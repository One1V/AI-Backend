## **What issue will it cause???**

**const express=require("express");
const app=express();**

**app.get("/",(req,res)=>{
    res.status(200);
})**

**app.listen(5000,()=>{
    console.log("Server is running...");
})**

The res.status() line is causing the bug as

`res.status(200)` **only sets the HTTP status code**. It does **not** send a response back to the client.

As a result, the browser or Postman will keep waiting because the request is never completed.(The website will keep loading).

Sets the status code to **200 OK**, but **doesn't end the request**.

```js
res.send("Hello from Express!");
```

* Sends the response body.
* Ends the request.
* If no status was set earlier, Express uses `200 OK`.

### Other common response methods

```js
res.send("Hello");          // Send text
res.json({ name: "Ayush" }); // Send JSON
res.status(404).send("Not Found");
res.status(201).json({ success: true });
res.sendFile(__dirname + "/index.html"); // Send an HTML file
```

A good way to remember it is:

* `res.status()` → **Choose the status code.**
* `res.send()` / `res.json()` / `res.sendFile()` → **Actually send the response and finish the request.**
