# Question 1. What is Linux? Why do companies use Linux servers?

## What is Linux?

**Linux** is an **open-source operating system** that manages a computer's hardware and provides an environment where applications can run.

Think of Linux as the **manager of the computer**.

When you write an Express application like:

```javascript
app.listen(5000);
```

your application is **not** talking directly to the CPU, RAM, disk, or network card.

Instead, the flow is:

```text
Express App
      ↓
Node.js Runtime
      ↓
Linux Operating System
      ↓
CPU
RAM
Disk
Network Card
```

Linux decides:

* Which process gets CPU time.
* Where your application's memory is stored.
* How files are read and written.
* Which process is allowed to use port 5000.
* How network packets reach your server.

Without an operating system, applications would have to control hardware themselves, which would be impractical and unsafe.

---

## Why do we need an operating system?

Imagine opening Google Chrome while VS Code, Spotify, and your Express server are all running.

Questions arise:

* Which application gets CPU time first?
* How is RAM divided among them?
* What happens if two applications try to write to the same file?
* Who decides which program can use port 80?

Linux coordinates all of this.

---

## Why do companies use Linux servers?

Most production backend servers run Linux because it is:

### 1. Stable

Servers are expected to run continuously.

A Linux server can often run for months without needing a reboot.

Example:

```text
Amazon EC2
Ubuntu
Uptime: 143 days
```

---

### 2. Fast and lightweight

Linux generally uses fewer system resources than a desktop operating system.

That leaves more CPU and memory available for:

* Node.js
* Redis
* MongoDB
* Nginx

instead of the operating system itself.

---

### 3. Secure

Linux has a strong permissions model.

Example:

```
-rw-------
```

Only the file owner can read or modify the file.

This is one reason secrets like `.env` files can be protected effectively.

---

### 4. Open source

Anyone can inspect, modify, and improve Linux.

Companies can:

* customize it,
* audit the code,
* avoid licensing costs.

This flexibility has helped Linux become the dominant server operating system.

---

### 5. Excellent networking

Backend applications constantly communicate over networks.

Linux provides robust networking features that power:

* Nginx
* Docker
* Kubernetes
* cloud servers
* load balancers

---

### 6. Huge ecosystem

Most backend tools are designed with Linux in mind:

* Node.js
* Docker
* Redis
* PostgreSQL
* MongoDB
* Nginx
* Git

Everything integrates naturally on Linux.

# A real backend example

Suppose you've deployed your portfolio backend.

```text
Internet
      ↓
Ubuntu Server
      ↓
Nginx
      ↓
Express
      ↓
MongoDB
```

When someone visits:

```
https://yourdomain.com/api/users
```

Linux is responsible for:

1. Receiving the network packet.
2. Passing it to Nginx (which is listening on port 443).
3. Allowing Nginx to forward the request to Express (for example, on port 5000).
4. Scheduling CPU time for both processes.
5. Managing memory used by each process.
6. Reading data from MongoDB.
7. Sending the response back over the network.

Linux is coordinating the entire journey behind the scenes.

# Backend engineer's perspective

As a backend engineer, Linux is where your application lives.

* create directories,
* edit configuration files,
* inspect logs,
* manage processes,
* configure permis2sions,
* connect via SSH,
* deploy applications,
* debug networking issues.

Even if your code is perfect, understanding Linux is often what lets you diagnose production problems quickly.

# Interview questions

### Q1. Is Linux an operating system?

A precise answer is:

> Linux technically refers to the **kernel**, but in everyday usage people often use "Linux" to mean a complete operating system distribution such as Ubuntu or Debian.

We'll explore the kernel in the next question.

### Q3. Does Node.js run directly on hardware?

No.

```
Node.js
   ↓
Linux
   ↓
Hardware
```

Linux provides the abstraction layer between applications and physical hardware.

---

Key takeaways

* Linux is the operating system that manages hardware and runs applications.
* Your backend application depends on Linux for CPU, memory, files, networking, and processes.
* Most production backend servers use Linux because it is stable, secure, efficient, and has an excellent ecosystem.
* As a backend engineer, Linux is a practical skill you'll use every time you deploy or troubleshoot an application.
