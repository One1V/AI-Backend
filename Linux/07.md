# **Question 7. What happens internally when you execute a Linux command?**

# Example 1

Suppose you type:

```bash
ls
```

You press **Enter**.

What happens?

---

## Step 1 — Terminal receives your input

## Step 2 — Shell reads the command

The shell receives:

```bash
ls
```

Now Bash starts analyzing it.

It asks:

> "Is `ls` a valid command?"

---

## Step 3 — Shell searches for the executable

How does Bash know where `ls` is?

It checks the **PATH** environment variable.

Example:

```bash
echo $PATH
```

Output might be:

```text
/usr/local/bin:/usr/bin:/bin
```

Bash searches these directories one by one.

It finds:

```text
/bin/ls
```

Think of it like searching for a book in a library.

```text
Shelf 1 ❌

Shelf 2 ❌

Shelf 3 ✅

Found!
```

---

## Step 4 — Shell asks the Kernel

Bash says:

> "Please start `/bin/ls`."

The kernel now takes over.

---

## Step 5 — Kernel creates a Process

The kernel:

* creates a new process,
* allocates memory,
* schedules CPU time.

Now `ls` is running.

```text
Kernel

↓

Process Created

↓

CPU Allocated
```

---

## Step 6 — `ls` requests directory contents

The `ls` program doesn't read the disk directly.

It asks the kernel:

> "Give me all files in the current directory."

The kernel:

* checks permissions,
* reads the filesystem,
* returns the filenames.

---

## Step 7 — Output returns

The `ls` program prints:

```text
server.js

package.json

node_modules

routes

controllers
```

The terminal displays the output.

---

# Backend Example

Now let's use a command you'll run every day.

```bash
node server.js
```

# Interview Questions

### Q1. What happens when you execute a Linux command?

A good answer:

> The terminal sends the command to the shell. The shell interprets it, finds the executable using the PATH environment variable, and requests the kernel to execute it. The kernel creates a process, allocates resources, runs the program, and the output is displayed in the terminal.

---

### Q2. Who creates a process?

**Answer:**

The **Linux kernel**.

---

### Q3. Who finds the executable?

**Answer:**

The **shell**, using the `PATH` environment variable.

---

Key Takeaways

* **Terminal** accepts your input and displays output.
* **Shell** interprets commands and finds executables.
* **PATH** tells the shell where to look for programs.
* **Kernel** creates processes and manages execution.
* Every backend command (`node`, `npm`, `git`, `docker`) follows this same lifecycle.
