# Module 1 – Linux Fundamentals

# **Question 8. Linux Filesystem Hierarchy (`/`, `/home`, `/etc`, `/var`, `/usr`, `/tmp`)**

---

# First Question

Suppose I ask you:

> **Where is Node.js installed?**

or

> **Where does Nginx store its configuration?**

or

> **Where are log files stored?**

Windows has:

```text
C:\Program Files

D:\Movies
```

Linux works differently.

Everything starts from **one root directory**.

---

# Linux has only ONE root

Unlike Windows,

Linux does **not** have:

```text
C:

D:

E:
```

Instead, Linux starts from one directory:

```text
/
```

Pronounced:

> **Root Directory**

Everything exists inside it.

Example:

```text
/
│
├── home
├── etc
├── var
├── usr
├── tmp
├── bin
├── boot
```

Think of `/` as the **root of a tree**.

---

# Important Directories

---

# 1. `/home`

This contains **user files**.

Example:

```text
/ home
     |
     ├── ayush
     ├── rahul
     └── john
```

If your username is `ayush`:

```text
/home/ayush
```

contains:

* Documents
* Downloads
* Desktop
* Projects

Example:

```text
/home/ayush/projects/backend
```

Most developers keep their code here.

---

## Backend Example

```text
/home/ayush/

        backend-project/

              server.js

              package.json

              .env
```

This is a normal place to develop your application.

---

# 2. `/etc`

Very important.

It stores **system configuration files**.

Think:

> **etc = settings**

Examples:

```text
/etc/nginx/

/etc/hosts

/etc/passwd
```

---

## Backend Example

When configuring Nginx:

```text
/etc/nginx/nginx.conf
```

or

```text
/etc/nginx/sites-available/default
```

You'll edit these files frequently during deployment.

---

# 3. `/var`

`var` means **variable data**.

This directory stores files that change frequently.

Examples:

* Logs
* Cache
* Databases
* Web server files

Example:

```text
/var/log
```

contains logs.

---

## Backend Example

Nginx logs:

```text
/var/log/nginx/access.log

/var/log/nginx/error.log
```

When your deployed API stops working, one of the first places you'll check is:

```bash
tail -f /var/log/nginx/error.log
```

---

# 4. `/usr`

This contains **installed software and shared resources**.

Many programs live here.

Example:

```text
/usr/bin
```

contains executables like:

```text
node

git

python
```

Earlier, we used:

```bash
which node
```

Output:

```text
/usr/bin/node
```

Now you know **why**.

---

# 5. `/tmp`

Temporary files.

Example:

```text
/ tmp

      image1

      temp.pdf

      cache.txt
```

Programs often use this directory for temporary data.

Many systems automatically clean it.

So don't store important files here.

---

## Backend Example

Suppose your API allows users to upload PDFs.

Flow:

```text
User Upload

↓

/tmp

↓

Process File

↓

Store in Cloud

↓

Delete Temporary File
```

This avoids cluttering permanent storage.

---

# Bonus Directories

You'll encounter these too.

---

## `/bin`

Contains essential command-line programs.

Examples:

```text
ls

cp

mv

cat
```

These are available even in minimal Linux environments.

---

## `/boot`

Contains files needed to start Linux.

You usually don't modify these during backend development.

---

## `/dev`

Represents hardware devices as files.

Examples:

* Hard disks
* USB drives
* Terminals

Advanced topic—not something you'll use often as a backend developer.

---

# Complete Picture

```text
/
│
├── home   → User files & projects
├── etc    → Configuration
├── var    → Logs & changing data
├── usr    → Installed software
├── tmp    → Temporary files
├── bin    → Essential commands
├── boot   → Boot files
```

---

# Backend Engineer's Perspective

Suppose you're deploying a Node.js app.

```text
Ubuntu Server

↓

/home/ubuntu/backend

↓

server.js
```

Configuration:

```text
/etc/nginx/nginx.conf
```

Logs:

```text
/var/log/nginx/error.log
```

Node executable:

```text
/usr/bin/node
```

Temporary uploads:

```text
/tmp
```

Each directory has a specific purpose.

# Interview Questions

### Q1. What is the root directory?

**Answer:**

> The root directory (`/`) is the top-level directory in the Linux filesystem. Every file and directory is located under it.

---

### Q2. Where are configuration files stored?

**Answer:**

> `/etc`

---

### Q3. Where are log files stored?

**Answer:**

> Most system and application logs are stored under `/var/log`.

---

### Q4. Where do developers usually keep projects?

**Answer:**

> Inside their home directory, such as `/home/username/projects`.

---

### Q5. What is `/tmp` used for?

**Answer:**

> Temporary files that applications need during execution.

---

## Key Takeaways

* Linux has **one root directory (`/`)**, unlike Windows' multiple drive letters.
* Important directories:

  * `/home` → User files and projects
  * `/etc` → Configuration files
  * `/var` → Logs and changing data
  * `/usr` → Installed software
  * `/tmp` → Temporary files
* Knowing where things are stored makes deployment and debugging much easier.
