## **Question 11. What is the Present Working Directory (`pwd`)?**

# What is a Directory?

First, remember:

* **File** → Stores data.
* **Directory (Folder)** → Stores files and other directories.

Example:

```text
/home
   └── ayush
        ├── Documents
        ├── Downloads
        └── backend-project
             ├── server.js
             ├── package.json
             └── .env
```

Here:

* `backend-project` is a **directory**.
* `server.js` is a **file**.

# The `pwd` Command

> "Currently, I am inside `/home/ayush`."

# Interview Question

### What is the Present Working Directory?

A good answer:

> The Present Working Directory (PWD) is the directory where the current shell session is operating. The `pwd` command displays its absolute path.
