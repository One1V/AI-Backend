
# **Question 13. What is the difference between Absolute and Relative Paths?**

This concept is used everywhere:

* `cd`
* `cp`
* `mv`
* `git`
* `docker`
* `npm`
* Express static files
* Nginx configuration

---

# First, what is a Path?

A **path** is simply the **address of a file or directory**.

# There are TWO types of paths

1. **Absolute Path**
2. **Relative Path**

### Absolute Path

An **absolute path** always starts from the **root directory (`/`)**.

It gives the complete address.

Example:

```text
/home/ayush/projects/backend/server.js
```

Think of it as a full postal address.

No matter where you currently are, Linux knows exactly where this file is.

---

## Example

Current directory:

```text
/home/ayush
```

Run:

```bash
cd /home/ayush/projects/backend
```

Linux goes directly there because you gave the complete path.

---

# Relative Path

A **relative path** starts from **your current working directory**.

Suppose:

```bash
pwd
```

shows:

```text
/home/ayush
```

Inside it:

```text
/home/ayush
│
└── projects
     └── backend
```

You can write:

```bash
cd projects/backend
```

Notice:

No `/` at the beginning.

Linux interprets it as:

> "Start from my current location."

---

### Relative Path

```bash
cd projects/backend
```

Starts from:

```text
/home/ayush
```

because that's your current directory.

```bash
cd backend
```

works because `backend` is inside `projects`.

---

# Example

Suppose you're already here:

```text
/home/ayush/projects/backend
```

To go to `server.js`, you can use:

```text
server.js
```

or

```text
./server.js
```

Here:

* `.` means **current directory**.
* `..` means **parent directory**.

---

# Understanding `.` and `..`

Suppose:

```text
/home/ayush/projects/backend
```

### `.`

Means:

```text
/home/ayush/projects/backend
```

(Current directory)

---

### `..`

Means:

```text
/home/ayush/projects
```

(Parent directory)

---

### `../frontend`

Means:

```text
/home/ayush/projects/frontend
```

---

# Common Interview Example

Suppose:

```bash
pwd
```

returns:

```text
/home/ayush/backend
```

You execute:

```bash
cat routes/user.js
```

Linux reads:

```text
/home/ayush/backend/routes/user.js
```

because `routes/user.js` is a **relative path**.

---

# Interview Questions

### Q1. What is an absolute path?

**Answer:**

> An absolute path specifies the complete location of a file or directory starting from the root directory (`/`).

---

### Q2. What is a relative path?

**Answer:**

> A relative path specifies the location of a file or directory relative to the current working directory.

---

### Q3. Which one starts with `/`?

**Answer:**

Absolute path.

---

### Q4. What does `..` represent?

**Answer:**

The parent directory (one level up).
