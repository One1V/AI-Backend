# **Question 17. What are Hidden Files?**

---

# What are Hidden Files?

A **hidden file** is simply a file whose **name starts with a dot (`.`)**.

Example:

```text
.env
.gitignore
.git
.bashrc
.profile
```

# Why are they hidden?

These files usually contain:

* Configuration
* Settings
* Environment variables
* Git metadata

They are hidden to keep your directory clean and to reduce the chance of accidentally modifying important configuration files.

---

# Common Hidden Files for Backend Developers

## 1. `.env`

Probably the most important hidden file.

Example:

```text
PORT=5000
MONGO_URI=...
JWT_SECRET=...
```

Never commit this to GitHub.

---

## 2. `.git`

Created when you run:

```bash
git init
```

It stores Git's internal data such as commit history and branch information.

You normally **never edit it manually**.

---

## 3. `.gitignore`

Example:

```text
node_modules/
.env
dist/
```

This tells Git which files or folders to ignore.

---

## 4. `.bashrc`

Located in your home directory:

```text
/home/ayush/.bashrc
```

It stores Bash configuration, such as aliases and environment variable settings.

We'll study it in Module 8.

---

## 5. `.profile`

Another configuration file that may be used when you log in, depending on your Linux distribution and shell configuration.

---

# Can I create my own hidden file?

Yes.

Example:

```bash
touch .secret
```

# Interview Questions

### Q1. What is a hidden file in Linux?

**Answer:**

> A hidden file is a file whose name starts with a dot (`.`). By default, it is not shown by the `ls` command.

---

### Q2. How do you view hidden files?

**Answer:**

```bash
ls -a
```

---

### Q3. Why is `.env` hidden?

**Answer:**

> Because it's a configuration file containing environment variables and secrets. Hidden files help keep configuration separate from regular project files.

---

### Q4. Does "hidden" mean "secure"?

**Answer:**

**No.**

Hidden only means:

> **Not shown by default.**

Anyone with permission can still view the file using:

```bash
cat .env
```

or

```bash
ls -a
```

So **hiding a file is not a security feature**.

---

# 🧠 Memory Trick

Remember:

```text
Starts with "." ?

Yes → Hidden File

No → Normal File
```

Examples:

```text
.env          ✅ Hidden
.git          ✅ Hidden
.gitignore    ✅ Hidden
server.js     ❌ Normal
package.json  ❌ Normal
```

## 🔥 Placement Tip

A common interview question is:

> **"How do you see hidden files in Linux?"**

The expected answer is simply:

```bash
ls -a
```

And if they ask:

> **"Why is `.env` hidden?"**

A good response is:

> "It's a configuration file containing environment variables. It's hidden by convention to keep project configuration separate from regular files, not to provide security."
>
>> **"If `.env` is a hidden file, why do you see it in VS Code?"**
>>
>
> A good answer is:
>
>> "Linux treats files beginning with `.` as hidden in terminal listings like `ls`. VS Code chooses to display hidden files by default because they're commonly used configuration files during development."
