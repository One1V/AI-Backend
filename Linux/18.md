## **Question 18. How does File Globbing (`*`, `?`, `[]`) work?**

---

# What is File Globbing?

**File globbing** is a feature of the **shell (Bash)** that lets you match multiple files using special wildcard characters.

Think of it as saying:

> "I don't know the exact filename, but I know a pattern."

**Important:** The **shell expands these patterns before the command runs.**

---

## Example

Suppose your directory contains:

```text
server.js
app.js
index.js
style.css
README.md
```

You type:

```bash
ls *.js
```

Bash changes it internally to:

```bash
ls server.js app.js index.js
```

Then `ls` runs.

Notice:

* `ls` doesn't understand `*`.
* **Bash** expands `*` first.

---

# 1. `*` (Star)

`*` means:

> **Match zero or more characters.**

# 2. `?` (Question Mark)

`?` means:

> **Match exactly one character.**

Example:

```text
a.js
b.js
ab.js
abc.js
```

Run:

```bash
ls ?.js
```

Output:

```text
a.js
b.js
```

Because:

* `a` = one character ✅
* `b` = one character ✅
* `ab` = two characters ❌
* `abc` = three characters ❌

---

# 3. `[]` (Character Set)

`[]` lets you match specific characters.

Suppose:

```text
app.js
backend.js
config.js
```

Run:

```bash
ls [ab]*
```

Meaning:

> Files starting with `a` or `b`.

Output:

```text
app.js
backend.js
```

`config.js` is ignored.

---

## Another Example

```bash
ls file[1-3].txt
```

Matches:

```text
file1.txt
file2.txt
file3.txt
```

Not:

```text
file4.txt
```

# Common Commands Using Globbing

### Delete all `.tmp` files

```bash
rm *.tmp
```

---

### Copy all JavaScript files

```bash
cp *.js backup/
```

---

### List all JSON files

```bash
ls *.json
```

---

### Move all images

```bash
mv *.png images/
```

---

# Important Interview Point

Remember:

The shell expands the wildcard.

For example:

You type:

```bash
ls *.js
```

Bash converts it to:

```bash
ls server.js app.js index.js
```

Then `ls` executes.

This is why we say:

> **Globbing is a shell feature, not an `ls` feature.**

# Interview Questions

### Q1. What is file globbing?

**Answer:**

> File globbing is a shell feature that matches filenames using wildcard patterns such as `*`, `?`, and `[]`.

---

### Q2. What does `*` mean?

**Answer:**

> Match zero or more characters.

---

### Q3. What does `?` mean?

**Answer:**

> Match exactly one character.

---

### Q4. What does `[abc]` mean?

**Answer:**

> Match exactly one character from the set `a`, `b`, or `c`.

# Backend Engineer's Perspective

Suppose your production server generates hundreds of log files:

```text
api.log
auth.log
nginx.log
redis.log
```

Instead of deleting them one by one:

```bash
rm api.log
rm auth.log
rm nginx.log
rm redis.log
```

You can simply run:

```bash
rm *.log
```

This is faster and is a common practice in Linux administration and backend development.

---

# 🧠 Memory Trick

Think of the wildcards like this:

```text
*   → Any number of characters

?   → Exactly one character

[]  → Choose from these characters
```

Examples:

```text
*.js       → All JavaScript files

?.txt      → One-letter text files

[a-c]*     → Files starting with a, b, or c
```

---

## 🔥 Placement Tip

A common interview question is:

> **What will `rm *.log` do?**

Correct answer:

> It deletes **all files in the current directory whose names end with `.log`**. The `*` is expanded by the shell before `rm` runs.

This understanding is more important than simply memorizing the command.
