
# **Mini Project: Build a Backend Project Structure Using Linux Commands Only**

## Goal

Without using VS Code, create this project structure **only through Linux commands**:

```text
backend/
│
├── controllers/
├── routes/
├── models/
├── middleware/
├── config/
├── uploads/
├── server.js
├── package.json
├── .env
├── .gitignore
└── README.md
```

---

## Step 1: Create the Project Folder

```bash
mkdir backend
```

Move into it:

```bash
cd backend
```

Check where you are:

```bash
pwd
```

Example:

```text
/home/ayush/backend
```

---

## Step 2: Create the Directories

```bash
mkdir controllers routes models middleware config uploads
```

---

## Step 3: Create the Files

```bash
touch server.js package.json .env .gitignore README.md
```

---

## Step 4: Verify the Structure

Since `.env` and `.gitignore` are hidden, run:

```bash
ls -la
```

Expected output (order may differ):

```text
controllers/
routes/
models/
middleware/
config/
uploads/
server.js
package.json
.env
.gitignore
README.md
```

---

## Step 5: Practice Navigation

Go into the routes folder:

```bash
cd routes
```

Check:

```bash
pwd
```

Go back:

```bash
cd ..
```

---

## Step 6: Create Route Files

```bash
touch routes/userRoutes.js
touch controllers/userController.js
touch models/User.js
```

Now your structure becomes:

```text
backend/
│
├── controllers/
│     └── userController.js
│
├── routes/
│     └── userRoutes.js
│
├── models/
│     └── User.js
│
├── middleware/
├── config/
├── uploads/
├── server.js
├── package.json
├── .env
├── .gitignore
└── README.md
```

---

# Commands You Used

| Command    | Purpose                           |
| ---------- | --------------------------------- |
| `pwd`    | Show current directory            |
| `cd`     | Change directory                  |
| `ls`     | List files                        |
| `ls -la` | Show all files (including hidden) |
| `mkdir`  | Create directories                |
| `touch`  | Create files                      |

# Interview Challenge

An interviewer might say:

> **"Create the basic structure for an Express project using only Linux commands."**

A good answer would be:

```bash
mkdir backend
cd backend
mkdir routes controllers models middleware config
touch server.js package.json .env .gitignore README.md
```

This demonstrates that you're comfortable working in a Linux environment.
