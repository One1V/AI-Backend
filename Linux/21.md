
# **How do `cat`, `less`, `more`, `head`, and `tail` differ?**

All of these commands are used to **view file contents**, but each has a different purpose.

---

# Suppose we have a file

```text
server.log
```

Contents:

```text
Server Started
MongoDB Connected
User Logged In
Request Received
Response Sent
Server Closed
```

Let's see how each command behaves.

---

# 1. `cat` (Concatenate)

The most common command.

It displays the **entire file** at once.

```bash
cat server.log
```

Output:

```text
Server Started
MongoDB Connected
User Logged In
Request Received
Response Sent
Server Closed
```

### When do we use it?

* Small files
* `.env`
* `package.json`
* `README.md`

Example:

```bash
cat .env
```

Output:

```text
PORT=5000
JWT_SECRET=abc123
MONGO_URI=...
```

---

# 2. `less`

Suppose a log file has **10,000 lines**.

If you use:

```bash
cat server.log
```

the terminal floods with output.

Instead:

```bash
less server.log
```

Now you can:

* Scroll up ⬆️
* Scroll down ⬇️
* Search using `/`
* Quit by pressing `q`

### When do we use it?

Large files like:

* Nginx logs
* Express logs
* Docker logs
* System logs

---

# 3. `more`

Very similar to `less`, but more limited.

```bash
more server.log
```

It displays one screen at a time.

Press:

* Space → Next page
* Enter → Next line

Modern Linux users usually prefer **`less`** because it has more features.

---

# 4. `head`

Shows the **first 10 lines** of a file.

```bash
head server.log
```

If the file has 1000 lines:

```text
Line 1
Line 2
...
Line 10
```

Only the beginning is shown.

### Show first 5 lines

```bash
head -5 server.log
```

---

# 5. `tail`

Shows the **last 10 lines**.

```bash
tail server.log
```

Output:

```text
...
Request Received
Response Sent
Server Closed
```

### Show last 20 lines

```bash
tail -20 server.log
```

---

# Which command is used most in backend?

Probably:

```bash
tail
```

because backend developers constantly check the latest log entries.

Example:

```bash
tail server.log
```

You immediately see the most recent requests and errors.

---

# Comparison Table

| Command  | Purpose                         |
| -------- | ------------------------------- |
| `cat`  | Show entire file                |
| `less` | View large files with scrolling |
| `more` | View one page at a time         |
| `head` | Show beginning of file          |
| `tail` | Show end of file                |

---

# Backend Example

Suppose your Express server crashes.

Logs contain 5000 lines.

You don't need the whole file.

You only care about the latest error.

Run:

```bash
tail server.log
```

You'll immediately see the last few log entries where the error occurred.
