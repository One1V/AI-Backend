
# **How does `tail -f` help monitor logs?**

⭐ **Importance:** **10/10**

If you deploy a backend application on Linux, you'll use `tail -f` regularly.

---

# First, what is `tail`?

Suppose your log file contains:

```text
Server Started
MongoDB Connected
User Login
Request Received
Response Sent
```

Run:

```bash
tail server.log
```

Output:

```text
Server Started
MongoDB Connected
User Login
Request Received
Response Sent
```

It shows the **last 10 lines** (or fewer if the file is shorter).

---

# What does `-f` mean?

`-f` stands for:

> **Follow**

Instead of showing the file once and exiting, Linux **keeps watching the file**.

Whenever new lines are added, they appear automatically.

---

## Real Example

Suppose you run:

```bash
tail -f server.log
```

Initially:

```text
Server Started
MongoDB Connected
```

A user opens your website.

Your Express app logs:

```javascript
console.log("GET /api/users");
```

Immediately, your terminal updates:

```text
Server Started
MongoDB Connected
GET /api/users
```

You didn't rerun the command. `tail -f` kept watching the file.

---


As new logs are written:

```text

↓

↓

```

they appear live in your terminal.

---

# Why is this useful?

Imagine your deployed backend suddenly returns **500 Internal Server Error**.

Instead of repeatedly doing:

```bash
cat server.log
```

or

```bash
tail server.log
```

every few seconds,

you simply run:

```bash
tail -f server.log
```

Now every new request and error appears in real time.

---

# Backend Example

Suppose your Express app logs:

```javascript
app.get("/users", (req, res) => {
    console.log("Users API Called");
});
```

Someone visits:

```text
http://yourdomain.com/users
```

Terminal running:

```bash
tail -f server.log
```

Shows:

```text
Users API Called
```

immediately.

---

# Nginx Example

Nginx stores access logs.

Watch them live:

```bash
tail -f /var/log/nginx/access.log
```

Every visitor generates a new line:

```text
192.168.1.5 GET / 200
192.168.1.6 GET /login 200
192.168.1.7 POST /api/login 200
```

---

# Exit `tail -f`

Since it's continuously watching the file, press:

```text
Ctrl + C
```

to stop it.

---

# Difference Between `tail` and `tail -f`

| Command              | Purpose                                  |
| -------------------- | ---------------------------------------- |
| `tail file.log`    | Show the last 10 lines once              |
| `tail -f file.log` | Keep showing new lines as they are added |
