

# **What is Regular Expression (Regex) in Linux?**

You **don't need to master regex** for backend internships, but you should know what it is and recognize a few common patterns.

---

# What is Regex?

A **Regular Expression (Regex)** is a **pattern used to search or match text**.

Think of it like:

> "I don't know the exact text, but I know the pattern."

---

## Example

Suppose your log file contains:

```text
GET /users
POST /login
GET /products
DELETE /user
```

You want **all lines starting with `GET`**.

Run:

```bash
grep "^GET" server.log
```

Output:

```text
GET /users
GET /products
```

Here:

```text
^GET
```

means:

> Starts with `GET`

---

# Why is Regex Useful?

Imagine a log file with **100,000 lines**.

You don't know the exact message.

But you know:

* It starts with `ERROR`
* It ends with `.js`
* It contains a number

Regex lets you search for those patterns.

---

# Only 5 Patterns You Should Know

## 1. `^` → Starts With

```bash
grep "^GET" server.log
```

Matches:

```text
GET /users
GET /products
```

Not:

```text
POST /login
```

---

## 2. `$` → Ends With

Suppose:

```text
server.js
index.js
README.md
```

Search:

```bash
grep ".js$" files.txt
```

Output:

```text
server.js
index.js
```

---

## 3. `.` → Any One Character

Suppose:

```text
cat
cot
cut
```

Regex:

```text
c.t
```

Matches:

```text
cat
cot
cut
```

Because `.` means **any single character**.

---

## 4. `*` → Zero or More

Example:

```text
ab
abb
abbb
abbbb
```

Regex:

```text
ab*
```

Matches all of them.

---

## 5. `[ ]` → Character Set

Example:

```text
cat
bat
hat
```

Regex:

```text
[cb]at
```

Matches:

```text
cat
bat
```

Not:

```text
hat
```

---

# Backend Example

Suppose your log contains:

```text
GET /users
POST /login
GET /products
POST /signup
```

Find only GET requests:

```bash
grep "^GET" server.log
```

---

Suppose you want JavaScript files:

```text
server.js
index.js
style.css
```

Regex:

```bash
grep ".js$" files.txt
```

Output:

```text
server.js
index.js
```

---

# Do You Need Regex for Backend?

Yes—but mostly in **JavaScript**, not Linux.

You'll use regex for:

* Email validation
* Phone number validation
* Password validation
* URL validation

Example in JavaScript:

```javascript
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
```

So learning the basics now will help later.

---

# Minimum Required for Internships

Know these symbols:

| Symbol    | Meaning                    |
| --------- | -------------------------- |
| `^`     | Starts with                |
| `$`     | Ends with                  |
| `.`     | Any one character          |
| `*`     | Zero or more               |
| `[abc]` | One character from the set |

That's enough.
