# **How does `wc` work?**

What is `wc`?

`wc` stands for:

> **Word Count**

It counts:

* Lines
* Words
* Characters
* Bytes

inside a file.

---

## Example

Suppose `notes.txt` contains:

```text
Hello Linux
Backend Engineering
```

Run:

```bash
wc notes.txt
```

Output:

```text
2 4 26 notes.txt
```

Meaning:

```text
2 → Lines
4 → Words
26 → Bytes (approximate file size in bytes)
```

---

# Count Only Lines (`-l`)

Backend Example

# Backend Example

Suppose your Express log contains:

```text
GET /users
POST /login
GET /products
```

How many requests are logged?

```bash
wc -l server.log
```

Output:

```text
3 server.log
```

# Minimum Required for Internships

Know these:

Count lines:

```bash
wc -l file.txt
```

Count words:

```bash
wc -w file.txt
```

Count errors:

```bash
grep "ERROR" server.log | wc -l
```

That's enough.
