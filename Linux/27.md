# **How do `sort`, `uniq`, and `cut` work?**

# 1. `sort`

`sort` arranges lines in alphabetical or numerical order.

```bash
sort names.txt
```

Output:

```text
Aman
Ayush
Rohit
Zara
```

---

## Backend Example

Suppose your log contains:

```text
ERROR
INFO
ERROR
DEBUG
INFO
```

Run:

```bash
sort server.log
```

Output:

```text
DEBUG
ERROR
ERROR
INFO
INFO
```

---

# 2. `uniq`

`uniq` removes **consecutive duplicate lines**.

Example:

```text
ERROR
ERROR
INFO
INFO
DEBUG
```

Run:

```bash
uniq server.log
```

Output:

```text
ERROR
INFO
DEBUG
```

---

## Important

This **doesn't work properly** if duplicates aren't together.

Example:

```text
ERROR
INFO
ERROR
```

Running:

```bash
uniq server.log
```

Output:

```text
ERROR
INFO
ERROR
```

Nothing changes.

That's why we usually combine it with `sort`.

---

# Common Pattern

```bash
sort server.log | uniq
```

Output:

```text
DEBUG
ERROR
INFO
```

This is the standard way.

---

# 3. `cut`

`cut` extracts specific columns from text.

Suppose:

```text
101 Ayush
102 Rahul
103 Priya
```

Save it as:

```text
students.txt
```

Run:

```bash
cut -d " " -f1 students.txt
```

Output:

```text
101
102
103
```

Explanation:

* `-d " "` → Delimiter is a space.
* `-f1` → First field.

---

Show names:

```bash
cut -d " " -f2 students.txt
```

Output:

```text
Ayush
Rahul
Priya
```

---

# Backend Example

Suppose your log contains:

```text
GET /users 200
POST /login 401
GET /products 200
```

If you want only the HTTP methods:

```bash
cut -d " " -f1 access.log
```

Output:

```text
GET
POST
GET
```

---

# Minimum Required

Know only these commands:

Sort:

```bash
sort file.txt
```

Remove duplicates:

```bash
sort file.txt | uniq
```

Extract first column:

```bash
cut -d " " -f1 file.txt
```

That's enough.

---

# Interview Questions

### Q1. What does `sort` do?

**Answer:**

Sorts lines alphabetically (or numerically with appropriate options).

---

### Q2. What does `uniq` do?

**Answer:**

Removes consecutive duplicate lines.

---

### Q3. Why is `sort | uniq` commonly used?

**Answer:**

Because `uniq` only removes **adjacent** duplicates. Sorting groups identical lines together first.

---

### Q4. What does `cut` do?

**Answer:**

Extracts specific fields (columns) from each line of a file.

---

# 🧠 Memory Trick

```text
sort → Arrange

uniq → Remove duplicate lines

cut → Extract columns
```
