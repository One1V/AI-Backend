
# **How do `nano` and `vim` differ?**

⭐ **Importance:** **8/10**

---

# What are `nano` and `vim`?

Both are **terminal-based text editors**.

They let you edit files **without using VS Code**.

Example:

```bash
nano .env
```

or

```bash
vim .env
```

Both open the `.env` file for editing.

---

# 1. `nano`

`nano` is **simple and beginner-friendly**.

Suppose you want to edit:

```bash
nano .env
```

You'll see something like:

```text
PORT=5000
MONGO_URI=...
JWT_SECRET=...
```

You can immediately start typing.

At the bottom, Nano shows helpful shortcuts like:

```text
^O  Save
^X  Exit
```

Here `^` means **Ctrl**.

So:

* `Ctrl + O` → Save
* `Ctrl + X` → Exit

---

## Why do beginners like Nano?

Because it behaves like a normal text editor.

* Just type.
* Save.
* Exit.

No special modes.

---

# 2. `vim`

`vim` is much more powerful.

Open a file:

```bash
vim .env
```

Unlike Nano, you **cannot immediately type**.

Why?

Because Vim has **different modes**.

---

## Vim Modes (Minimum Required)

### Normal Mode

Default mode.

You can:

* Move around
* Delete lines
* Copy lines
* Search

You **cannot type text**.

---

### Insert Mode

Press:

```text
i
```

Now you can type normally.

---

### Save and Exit

Press:

```text
Esc
```

to return to Normal Mode.

Then type:

```text
:wq
```

and press Enter.

Meaning:

* `w` → Write (Save)
* `q` → Quit

---

### Exit Without Saving

```text
:q!
```

---

# Comparison

| Nano                     | Vim                                                                |
| ------------------------ | ------------------------------------------------------------------ |
| Easy to learn            | Steeper learning curve                                             |
| Start typing immediately | Press`i` to type                                                 |
| Good for beginners       | Preferred by many experienced developers and system administrators |
| Simple editing           | Powerful editing features                                          |

# Backend Example

Suppose your production server has:

```text
.env
```

You need to change:

```text
PORT=5000
```

to

```text
PORT=8000
```

Using Nano:

```bash
nano .env
```

Edit.

Save.

Exit.

Done.

---

Suppose you need to quickly edit:

```text
/etc/nginx/nginx.conf
```

Many servers have Vim installed by default.

You can use:

```bash
vim /etc/nginx/nginx.conf
```
