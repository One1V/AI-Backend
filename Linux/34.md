# **`chmod` (Change Mode) – Numeric and Symbolic Permissions**

⭐ **Importance:** ⭐⭐⭐⭐⭐ (One of the most important Linux commands)

After this lesson, you'll understand commands like:

```bash
chmod 755 folder
chmod 644 file
```

These are used in almost every Linux deployment guide.

---

# What is `chmod`?

`chmod` stands for:

> **Ch**ange **Mod**e

It changes the permissions of a file or directory.

---

# Two Ways to Use `chmod`

## 1. Numeric Mode (Most Common)

Numbers represent permissions.

| Permission  | Value |
| ----------- | ----: |
| Read (r)    |     4 |
| Write (w)   |     2 |
| Execute (x) |     1 |

Linux adds these values together.

---

## Examples

### Read + Write + Execute

```text
4 + 2 + 1 = 7
```

So:

```text
7 = rwx
```

---

### Read + Write

```text
4 + 2 = 6
```

```text
6 = rw-
```

---

### Read Only

```text
4
```

```text
4 = r--
```

---

### Read + Execute

```text
4 + 1 = 5
```

```text
5 = r-x
```

---

# Understanding `755`

```bash
chmod 755 folder
```

Break it into three numbers:

```text
7 5 5
```

These represent:

```text
User     Group     Others
```

So:

| Category | Number | Permission |
| -------- | ------ | ---------- |
| User     | 7      | rwx        |
| Group    | 5      | r-x        |
| Others   | 5      | r-x        |

Meaning:

* Owner can read, write, and execute.
* Group can read and execute.
* Others can read and execute.

This is **very common for folders**.

---

# Understanding `644`

```bash
chmod 644 file.txt
```

Break it down:

```text
6 4 4
```

| Category | Number | Permission |
| -------- | ------ | ---------- |
| User     | 6      | rw-        |
| Group    | 4      | r--        |
| Others   | 4      | r--        |

Meaning:

* Owner can read and edit.
* Everyone else can only read.

This is **very common for files**.

---

# Why 755 for folders?

Suppose you have:

```text
backend/
```

You want:

* You can edit it.
* Others can enter and read it.

So:

```bash
chmod 755 backend
```

---

# Why 644 for files?

Suppose:

```text
server.js
```

People should be able to read it.

Only you should edit it.

So:

```bash
chmod 644 server.js
```

---

# Symbolic Mode

Instead of numbers, use letters.

```text
u = User

g = Group

o = Others

a = All
```

Examples:

Give execute permission to owner:

```bash
chmod u+x deploy.sh
```

Remove write permission from group:

```bash
chmod g-w file.txt
```

Give read permission to everyone:

```bash
chmod a+r README.md
```

For internships, **numeric mode is more important**.

---

# Real Backend Example

Suppose you create:

```text
deploy.sh
```

Initially:

```text
-rw-r--r--
```

You try:

```bash
./deploy.sh
```

Linux says:

```text
Permission denied
```

Why?

Because it isn't executable.

Fix:

```bash
chmod +x deploy.sh
```

Now:

```bash
./deploy.sh
```

works.

---

# Minimum Required

Remember these two:

```text
755 → Folder

644 → File
```

And:

```bash
chmod +x script.sh
```

to make a script executable.

---

# Interview Questions

### Q1. What does `chmod` do?

**Answer:**

It changes the permissions of a file or directory.

---

### Q2. What does `755` mean?

**Answer:**

Owner gets `rwx`, while Group and Others get `r-x`.

---

### Q3. What does `644` mean?

**Answer:**

Owner gets `rw-`, while Group and Others get `r--`.

---

### Q4. Why do we use `chmod +x`?

**Answer:**

To make a file executable, such as a shell script.

---

# 🧠 Memory Trick

```
7 = rwx = 4+2+1

6 = rw-

5 = r-x

4 = r--
```

The numbers are simply the sum of:

* Read = 4
* Write = 2
* Execute = 1

## 🎯 Quick Revision

* `chmod` = Change permissions.
* `755` = `rwx r-x r-x` (commonly used for directories).
* `644` = `rw- r-- r--` (commonly used for files).
* `chmod +x file` = Make a script executable.
