# Difference Table

| Program               | Process                    |
| --------------------- | -------------------------- |
| Stored on disk        | Running in memory          |
| Passive               | Active                     |
| Doesn't use CPU       | Uses CPU                   |
| Doesn't use RAM       | Uses RAM                   |
| Static                | Dynamic                    |
| Example:`server.js` | Example:`node server.js` |

---

### Q2. Is `server.js` a process?

**Answer:**

No.

It is a program.

Running:

```bash
node server.js
```

creates the process.

---

### Q3. Why does a process use RAM?

**Answer:**

Because when a program executes, Linux loads it into memory so the CPU can run its instructions.
