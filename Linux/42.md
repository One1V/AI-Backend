
# Module 5 – Question 42

# **Program vs Process**

# Definition

### Program

A **program** is a file stored on disk.

Examples:

```text
server.js
chrome.exe
python
nginx
```

A program **does nothing** until it is executed.

---

### Process

A **process** is a program that is currently running.

Example:

```bash
node server.js
```

Now `server.js` becomes a running process.

---

# Example 1 (MERN Backend)

Your project:

```text
backend/
│
├── server.js
├── package.json
└── routes/
```

At this point:

```text

```

---

You execute:

```bash

```

```bash
node server.js
```

Linux creates:

```text
Node Process
```

Now your backend is alive.

# Can One Program Create Multiple Processes?

**Yes.**

Example:

Open Chrome.

Now open:

* 10 tabs

Chrome creates multiple processes.

Similarly,

one Node application can also create child processes using Node.js APIs.

# Memory Usage

Program:

```text
Stored on SSD

No CPU

No RAM
```

Process:

```text
Loaded into RAM

Uses CPU

Uses Memory
```

That's why your laptop becomes slow if too many processes are running.

# Interview Questions

### Q1. What is the difference between a program and a process?

**Answer:**

A program is a file stored on disk, while a process is a running instance of that program executing in memory.

---

### Q2. Is `server.js` a process?

**Answer:**

No.

It is a program.

Running:

```bash
node server.js
```

creates the process.

---

### Q3. Why does a process use RAM?

**Answer:**

Because when a program executes, Linux loads it into memory so the CPU can run its instructions.
