# Q52 — What is an IP Address? Private vs Public IP

An **IP address** is an address used to identify a device/interface on a network so that data can be sent to the correct destination.

# 1. Example

Your Linux VPS might have:

```text
Public IP: 203.0.113.25
```

Your home network might have:

```text
Private IP: 192.168.1.10
```

These serve different purposes.

---

# 2. Private IP

A **private IP** is used inside a private/local network.

Common private IPv4 ranges are:

```text
10.0.0.0        → 10.255.255.255

172.16.0.0      → 172.31.255.255

192.168.0.0     → 192.168.255.255
```

For example:

```text
Your Home Network

Router
  │
  ├── Laptop       192.168.1.10
  ├── Phone        192.168.1.11
  └── TV           192.168.1.12
```

These addresses are generally **not directly routable on the public internet**.

---

# 3. Public IP

A **public IP** identifies a device/interface that can communicate across the public internet, subject to firewall and routing rules.

For example:

```text
Internet
    ↓
203.x.x.x
    ↓
Your VPS
```

When you rent a VPS, the provider normally gives it a public IP.

You can then SSH into it:

```bash
ssh user@203.x.x.x
```

---

# 4. Your MERN deployment example

Suppose you have:

```text
Linux VPS

Public IP:
203.0.113.25
```

Inside the VPS:

```text
Express
localhost:5000
```

Nginx:

```text
port 80/443
```

So the architecture becomes:

```text
                 Internet
                    ↓
             Public IP
          203.0.113.25
                    ↓
                  Nginx
                 :80/:443
                    ↓
             localhost:5000
                    ↓
              Express
```

This is a very common deployment pattern.

---

# 5. Private IP in a backend architecture

Private IPs become particularly important when you have multiple servers.

For example:

```text
                    Internet
                       ↓
                  Public IP
                       ↓
                     Nginx
                       ↓
              Backend Server
              Private IP
              10.0.1.20
                 ↙      ↘
                ↓        ↓
        Redis Server    DB Server
        10.0.2.10      10.0.3.10
```

The backend can communicate with Redis and the database over the private network without exposing those services directly to the internet.

That's a common cloud architecture.

---

# 6. Public vs Private

|                   | Public IP              | Private IP                   |
| ----------------- | ---------------------- | ---------------------------- |
| Used for          | Internet communication | Internal network             |
| Globally routable | Generally yes          | No                           |
| Example           | `8.8.8.8`            | `192.168.1.10`             |
| Typical use       | VPS, public servers    | Laptop, internal servers, DB |
| Internet-facing   | Can be                 | Not directly                 |

---

# 7. How to find your Linux machine's IP

On Linux:

```bash
ip addr
```

or:

```bash
ip a
```

You may see:

```text
inet 192.168.1.10/24
```

That's a private IP.

You can also inspect your routes:

```bash
ip route
```

# 8. Important connection with localhost

You just learned:

```text
localhost = this machine
127.0.0.1 = loopback
```

Now add:

```text
Private IP = address on a private network
Public IP = address used for public network access
```

For example:

```text
VPS

localhost
127.0.0.1
    ↓
Express


Private IP
10.0.0.20
    ↓
Internal network


Public IP
203.0.113.25
    ↓
Internet
```

---

# 9. Don't confuse IP with port

This is extremely important.

An **IP address identifies the machine/interface**.

A **port identifies a network service on that machine**.

For example:

```text
203.0.113.25:5000
       ↑       ↑
       IP     Port
```

You can think:

```text
IP   = Building address
Port = Apartment/department
```

So:

```text
203.0.113.25:80
```

might be Nginx/HTTP, while:

```text
203.0.113.25:5000
```

could be your Express application if that port is exposed.

# 🧠 Interview Answer

### "What is an IP address?"

> **An IP address is a numerical address assigned to a network interface that allows devices to identify and communicate with each other over a network.**

### "What's the difference between public and private IP?"

> **A public IP is used for communication over the public internet, while a private IP is used within a private network and isn't directly routable over the public internet.**

### "Give an example."

```text
Private IP → 192.168.1.10
Public IP  → 203.x.x.x
```
