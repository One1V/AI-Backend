# Q61 — What is `apt`?

`apt` is the **package manager used by Debian-based Linux distributions**, including Ubuntu.

In simple terms:

> **`apt` helps you install, update, upgrade, and remove software on Linux.**

Since you're learning Ubuntu for backend deployment, `a` is one of the commands you'll use regularly

---

## 1. Why do we need a package manager?

Suppose you want to install Nginx.

Without a package manager, you'd have to:

```text
Find software
   ↓
Download it
   ↓
Find dependencies
   ↓
Install dependencies
   ↓
Configure everything
   ↓
Install software
```

That's painful.

With `apt`:

```bash
sudo apt install nginx
```

Ubuntu handles much of this for you.

```text
apt
 ↓
Repository
 ↓
Download package
 ↓
Resolve dependencies
 ↓
Install
```

---

# 2. What is a package?

A **package** is software bundled in a format that Linux's package-management system can install and manage.

Examples:

```text
nginx
git
curl
vim
redis
```

You can search for packages:

```bash
apt search nginx
```

---

# 3. Installing software

For example:

```bash
sudo apt install nginx
```

Break it down:

```text
sudo
 ↓
Run with elevated privileges

apt
 ↓
Package manager

install
 ↓
Action

nginx
 ↓
Package
```

So:

```bash
sudo apt install nginx
```

means:

> "Install the Nginx package using administrator privileges."

---

# 5. Where does `apt` get software?

Ubuntu has **package repositories**.

Conceptually:

```text
Your VPS
   │
   │ apt
   ▼
Ubuntu repositories
   │
   ▼
Package
   │
   ▼
Dependencies
   │
   ▼
Installed software
```

For example:

```bash
sudo apt install git
```

APT finds the appropriate Git package and its dependencies from configured repositories.

---

# 6. `apt update`

This command is frequently misunderstood.

```bash
sudo apt update
```

**does not normally upgrade your installed software.**

Instead, it refreshes the package information available from configured repositories.

Think:

```text
apt update
     ↓
"What's available?"
```

It updates your local package lists.

---

# 7. `apt upgrade`

Now:

```bash
sudo apt upgrade
```

actually upgrades installed packages to newer available versions, subject to APT's dependency rules.

Think:

```text
apt update
     ↓
Refresh package information

apt upgrade
     ↓
Install available upgrades
```

---

# 8. Very common sequence

When working with a fresh Ubuntu VPS, you'll often see:

```bash
sudo apt update
sudo apt upgrade
```

Then install what you need:

```bash
sudo apt install nginx
```

For example:

```text
Fresh VPS
   ↓
apt update
   ↓
apt upgrade
   ↓
Install Git
   ↓
Install Node.js
   ↓
Install Nginx
```

---

# 9. Removing software

To remove a package:

```bash
sudo apt remove nginx
```

This removes the package while generally leaving some configuration files behind.

You can also use:

```bash
sudo apt purge nginx
```

`purge` removes the package and its associated configuration files managed by the package.

For your current level, remember:

```text
remove → remove software
purge  → remove software + package configuration
```

---

# 10. Checking whether software is installed

You can use:

```bash
apt list --installed
```

Or:

```bash
dpkg -l
```

For example:

```bash
apt list --installed | grep nginx
```

# 11. Real backend deployment example

Imagine you've rented an Ubuntu VPS and want to deploy your application.

Initially:

```text
Ubuntu VPS
   │
   ├── No Nginx
   ├── No Git
   └── No other tools you need
```

You can install them:

```bash
sudo apt update
sudo apt install nginx git
```

Now:

```text
Ubuntu VPS
   │
   ├── Nginx
   └── Git
```

Then you can configure:

```text
Internet
   ↓
Nginx
   ↓
Node.js / Express
```

This is exactly why `apt` matters to you as a backend developer.

# 12. `apt` vs `npm`

Don't confuse these.

### `apt`

Installs **system-level software**:

```bash
sudo apt install nginx
sudo apt install git
```

### `npm`

Installs **Node.js project dependencies**:

```bash
npm install express
npm install mongoose
```

Think:

```text
Linux system
    ↓
   apt
    ↓
Nginx / Git / system packages


Node project
    ↓
   npm
    ↓
Express / Mongoose / JWT libraries
```

---

# 13. `apt` vs `apt-get`

You'll sometimes see:

```bash
apt-get install nginx
```

and:

```bash
apt install nginx
```

Both interact with Debian's package-management system.

For normal interactive use, **`apt` is generally the simpler command to use**.

You'll still encounter `apt-get` in older tutorials and scripts.

# 🧠 Interview Answer

If an interviewer asks:

> **"What is apt in Linux?"**

A good answer:

> **"`apt` is the package management tool used on Debian-based distributions such as Ubuntu. It allows us to install, update, upgrade, search, and remove software packages while handling their dependencies."**

If they ask:

> **"What's the difference between `apt update` and `apt upgrade`?"**

Say:

> **"`apt update` refreshes the local package information from the configured repositories, while `apt upgrade` actually installs available updates for installed packages."**
