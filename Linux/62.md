# Q62 — `apt update` vs `apt upgrade`

This is one of the most common Linux questions, and the difference is actually simple:

```text
apt update
    ↓
"Find out what's available"

apt upgrade
    ↓
"Actually install the updates"
```

---

# 1. `apt update`

Run:

```bash
sudo apt update
```

It contacts the repositories configured on your Ubuntu system and downloads the **latest package metadata**.

It does **not normally upgrade your installed packages**.

Think of it like checking a software store:

```text
Your VPS
   ↓
"What's the latest version available?"
   ↓
Ubuntu repositories
   ↓
Package information
   ↓
Local package lists updated
```

# 2. `apt upgrade`

Now run:

```bash
sudo apt upgrade
```

APT compares:

```text
Installed versions
        ↓
Available versions
```

and installs available upgrades according to its dependency rules.

So:

```text
apt update
     ↓
Refresh information

apt upgrade
     ↓
Apply upgrades
```

---

# 3. Real VPS example

Imagine you rent a fresh Ubuntu VPS.

You connect:

```bash
ssh ubuntu@YOUR_SERVER_IP
```

Then:

```bash
sudo apt update
```

You might see:

```text
X packages can be upgraded.
```

This means:

> APT has discovered newer versions.

Then:

```bash
sudo apt upgrade
```

Now those packages can actually be upgraded.

---

# 5. Important misconception

❌ Wrong:

> "`apt update` updates Ubuntu."

More accurate:

> "`apt update` updates the package lists/metadata."

✅ `apt upgrade` is the command that upgrades installed packages.

---

# 6. What actually gets downloaded?

When you run:

```bash
sudo apt update
```

APT downloads information about packages from configured repositories.

Conceptually:

```text
Ubuntu Repository
       ↓
Package metadata
       ↓
Your VPS
       ↓
APT's local package lists
```

When you run:

```bash
sudo apt upgrade
```

APT downloads the actual newer package files and installs them.

```text
Repository
     ↓
Package files
     ↓
VPS
     ↓
Installation
```

# 8. Typical server setup

When you get a new Ubuntu VPS, you might do:

```bash
sudo apt update
sudo apt upgrade
```

Then install required software:

```bash
sudo apt install git nginx
```

Then configure your application.

Eventually:

```text
VPS
│
├── Git
├── Nginx
├── Node.js
└── Your backend
```

# 10. Interview answer

If asked:

### "Difference between apt update and apt upgrade?"

Say:

> **"`apt update` refreshes the package metadata from configured repositories. It doesn't normally modify the installed software. `apt upgrade` uses that updated information to download and install newer versions of installed packages."**

That's a strong placement-level answer.
