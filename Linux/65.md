# Q65 — Mini Project: Install Node.js, Git, and Nginx

This is the **final question of Module 7 — Package Management**.

The goal is to take a relatively fresh Ubuntu VPS and install the basic tools you'll need to deploy your backend.

---

# 🎯 Goal

By the end, your server should have:

```text
Ubuntu VPS
│
├── Git
├── Node.js + npm
└── Nginx
```

This is the first step toward your eventual architecture:

```text
Internet
   ↓
Nginx
   ↓
Node.js / Express
   ↓
MongoDB
```

---

# Step 1 — SSH into your VPS

From your laptop:

```bash
ssh username@SERVER_IP
```

For example:

```bash
ssh ubuntu@203.0.113.25
```

You should now be inside the remote Linux server.

Verify:

```bash
whoami
```

and:

```bash
hostname
```

---

# Step 2 — Update package information

First:

```bash
sudo apt update
```

Remember:

```text
apt update
     ↓
Refresh package information
```

Then upgrade installed packages if appropriate:

```bash
sudo apt upgrade
```

---

# Step 3 — Install Git

Run:

```bash
sudo apt install git
```

Verify:

```bash
git --version
```

Example:

```text
git version 2.x.x
```

Now your VPS can interact with Git repositories.

For example, later you'll be able to:

```bash
git clone <your-repository>
```

---

# Step 4 — Install Node.js

This part deserves attention.

Ubuntu repositories can provide Node.js, but the version available depends on the Ubuntu release and configured repositories.

For learning, you can first check what's available:

```bash
apt policy nodejs
```

Then, if the available version is suitable:

```bash
sudo apt install nodejs npm
```

Verify:

```bash
node -v
```

and:

```bash
npm -v
```

You should see version numbers.

---

## ⚠️ Production note

For real projects, don't blindly install whatever Node.js version happens to be in the default Ubuntu repository.

You normally choose a supported Node.js release deliberately, often using a version manager such as **nvm** or a trusted Node.js distribution/repository.

For your Linux learning project, the important concept is:

```text
Linux
 ↓
Package manager
 ↓
Node.js
 ↓
npm
 ↓
Express application
```

---

# Step 5 — Install Nginx

Run:

```bash
sudo apt install nginx
```

Check the version:

```bash
nginx -v
```

You should get something similar to:

```text
nginx version: nginx/1.xx.x
```

---

# Step 6 — Check Nginx service

Run:

```bash
sudo systemctl status nginx
```

You should see something similar to:

```text
Active: active (running)
```

This connects to your previous learning about **services and systemd**.

```text
apt
 ↓
Install Nginx
 ↓
systemd
 ↓
nginx service
 ↓
Running
```

---

# Step 7 — Test Nginx locally

On the VPS:

```bash
curl http://localhost
```

You should receive HTML from Nginx.

This proves:

```text
Nginx
 ↓
Listening
 ↓
HTTP response
```

---

# Step 8 — Test Nginx from your laptop

If your VPS firewall/network configuration allows HTTP traffic, open:

```text
http://SERVER_IP
```

in your browser.

You should see the Nginx default page.

The architecture is now:

```text
Your Laptop
     │
     │ HTTP
     ▼
Internet
     │
     ▼
Linux VPS
     │
     ▼
Nginx :80
```

---

# Step 9 — Verify the ports

Run:

```bash
sudo ss -ltnp
```

You may see services listening on ports such as:

```text
:22
:80
```

Meaning:

```text
:22 → SSH
:80 → Nginx/HTTP
```

Later you'll add your Express application:

```text
:5000 → Express
```

So eventually:

```text
Internet
   │
   ├── :22 → SSH
   │
   └── :80/:443 → Nginx
                     │
                     ▼
                  :5000
                     │
                  Express
```

---

# Step 10 — Verify everything

Run:

```bash
git --version
```

```bash
node -v
```

```bash
npm -v
```

```bash
nginx -v
```

And:

```bash
sudo systemctl status nginx
```

You should now have:

```text
Git       ✅
Node.js   ✅
npm       ✅
Nginx     ✅
```

# 🎯 Q65 Interview Answer

If asked:

> **"How would you prepare a fresh Ubuntu server for a Node.js deployment?"**

A concise answer:

> "I'd connect through SSH, update the package lists, install the required system tools such as Git and Nginx, install a supported Node.js version, verify the services and listening ports, and then deploy and configure the application."
