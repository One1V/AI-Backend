# Question 5: What is a Web Server?

This is one of the most fundamental backend questions. Most beginners think:

> "A web server is just software that hosts websites."

That's only partly correct.

---

# Definition

A **web server** is software that:

1. Waits for HTTP/HTTPS requests from clients (usually browsers).
2. Understands those requests.
3. Finds the requested resource.
4. Sends the appropriate response back.

The response can be:

* HTML
* CSS
* JavaScript
* Images
* Videos
* JSON
* PDFs
* Error pages

---

# Why do we need a web server?

Suppose you created:

```text
index.html
style.css
logo.png
```

These files are sitting on your laptop.

Can someone in another city access them?

❌ No.

Your laptop is just storing files.

You need software that:

* Listens on a port (80 or 443)
* Waits for incoming requests
* Reads the requested file
* Sends it over the internet

That software is called a **web server**.

---

# Internal Working

Suppose you type:

```text
https://mywebsite.com
```

### Step 1

Browser asks DNS:

```text
Where is mywebsite.com?
```

DNS returns the server IP.

---

### Step 2

Browser opens a connection.

---

### Step 3

Browser sends:

```http
GET /
```

---

### Step 4

Web server receives it.

---

### Step 5

Web server checks:

```text
Is "/" mapped to index.html?
```

Yes.

---

### Step 6

It reads:

```text
index.html
```

from disk.

---

### Step 7

Returns:

```html
HTTP/1.1 200 OK

<html>

...
```

Browser displays the page.

---

# Is Express a Web Server?

This is a common interview question.

### Technically

Node.js itself can act as a web server.

Example:

```javascript
const http = require("http");

http.createServer((req, res) => {
    res.end("Hello");
});
```

This listens for HTTP requests.

Express is built on top of Node's HTTP server and makes building web applications much easier by providing routing, middleware, and other features.

---

# Is Nginx a Web Server?

Yes.

Nginx can:

* Serve HTML
* Serve CSS
* Serve JS
* Serve Images
* Serve Videos

without any Express application.

Example:

```text
Browser

↓

Nginx

↓

index.html
```

---

# Then Why Use Express?

Suppose the request is:

```text
GET /api/user
```

This requires:

* Database lookup
* Authentication
* Business logic

Nginx doesn't execute your JavaScript business logic.

So:

```text
Browser

↓

Nginx

↓

Express

↓

MongoDB
```

Nginx serves static content, while Express handles dynamic application logic.

---

# Static vs Dynamic

### Static Content

Always the same.

Examples:

```text
logo.png

style.css

index.html
```

Every user gets identical content.

---

### Dynamic Content

Depends on the user.

Example:

```text
GET /profile
```

User A:

```json
{
"name":"Ayush"
}
```

User B:

```json
{
"name":"Rahul"
}
```

The response changes, so the backend generates it dynamically.

---

# Web Server vs Application Server

| Web Server            | Application Server            |
| --------------------- | ----------------------------- |
| Serves static files   | Runs business logic           |
| Handles HTTP requests | Executes application code     |
| Example: Nginx        | Example: Express, Spring Boot |

Modern systems often use **both together**.

---

# Real-World Example: Amazon

When you open Amazon's homepage:

The request first reaches a web server/reverse proxy layer (such as Nginx or similar technology).

If it's asking for:

* Images
* CSS
* JavaScript

those can often be served directly.

If it's asking for:

```text
/api/orders
```

the request is forwarded to backend services.

This separation improves performance and scalability.

---

# Interview Questions

### Q1. What is a web server?

**Answer:**

> A web server is software that listens for HTTP/HTTPS requests, processes them, and returns resources such as HTML, CSS, JavaScript, images, or other content to clients.

---

### Q2. Is Nginx a web server?

**Answer:**

> Yes. Nginx is a web server that can also function as a reverse proxy, load balancer, cache, and SSL/TLS terminator.

---

### Q3. Is Express a web server?

**Answer:**

> Express is a web application framework built on top of Node.js's HTTP server. It simplifies creating web applications and APIs, while Node's underlying HTTP module handles the actual web server functionality.

---

# Key Takeaways

* A web server receives HTTP/HTTPS requests and returns resources.
* Nginx is a web server optimized for networking and serving static content.
* Express builds dynamic responses using business logic.
* Modern production systems typically use **Nginx in front of Express**, combining the strengths of both.
