
### Projects you'll build during the journey

* **Project 1:** Serve a static portfolio using Nginx.
* **Project 2:** Put your Express backend behind Nginx as a reverse proxy.
* **Project 3:** Host React frontend + Express backend on one server using Nginx.
* **Project 4:** Load-balance two Express servers with Nginx.
* **Project 5:** Enable HTTPS with SSL certificates.
* **Project 6:** Deploy a production-ready MERN app with PM2 + Nginx.
* **Project 7:** Dockerize a MERN app and use Nginx as the gateway.
* **Final Project:** Build a production-style architecture with React, Nginx, Express, Redis, MongoDB, Docker, and monitoring.
